# CatChase 猫咪互动游戏

> 专为家养猫咪设计的触屏互动游戏 —— 让 AI 服务于人宠共乐

---

## 一、项目简介与产品定位

### 项目简介

CatChase 是一款专为家养猫咪设计的触屏互动游戏。屏幕上会出现小鱼、激光、昆虫、羽毛、青蛙、蝴蝶、蜘蛛、蟋蟀等 8 种动态猎物，猫咪通过拍打屏幕进行捕猎互动。每一个设计决策都围绕猫咪的生理特征与捕猎本能展开：猎物大小适配猫咪视觉焦距，运动速度模拟真实猎物逃逸行为，声音反馈激发捕猎本能。

作品填补了"专为真实猫咪而非人类玩家设计"的电子游戏空白，将 AI 交互设计理念应用于人宠共乐场景，帮助工作繁忙的宠物主人让猫咪获得适度运动与刺激。

### 产品定位

- **目标用户**：18-35 岁城市养猫青年、多猫家庭、宠物博主与内容创作者
- **使用场景**：主人上班时猫咪独自娱乐、主人陪伴时人宠互动、猫咪精力过剩时消耗体力
- **核心价值主张**：
  - **专为猫咪设计**：不是人类视角的"可爱"，而是猫咪视角的"有趣"
  - **自适应智能**：根据猫咪行为自动调节难度与休息提醒
  - **高度自定义**：8 种猎物 × 8 套主题 × 无限配置组合
  - **零依赖部署**：单文件 HTML，即开即玩，无需安装

## 三、启动方式与环境变量说明

### 启动方式

本项目为**纯前端单文件 HTML 应用**，零外部依赖、零构建步骤，提供三种启动方式：

#### 方式一：直接打开（最简单）
双击 `index.html` 文件，系统默认浏览器即可运行游戏，无需任何安装。

#### 方式二：本地静态服务器（推荐开发调试）
```bash
# Python 3
python -m http.server 8000

# 或 Node.js (需先安装 http-server)
npx http-server -p 8000
```
浏览器访问 `http://localhost:8000/index.html`。

#### 方式三：在线部署
将 `index.html` 上传至任意静态托管平台（GitHub Pages、Vercel、Netlify 等）即可公开访问。

### 环境变量说明

**本项目无需任何环境变量配置。**

原因如下：
- **纯前端架构**：所有逻辑在浏览器端执行，无后端服务、无数据库、无 API 密钥
- **程序化内容生成**：全部图形与音频通过代码实时合成，不依赖任何外部素材或第三方服务
- **本地持久化**：用户配置与游戏数据通过浏览器 `localStorage` 存储，无需服务端
- **零配置开箱即用**：打开即玩，无需 `.env` 文件、无需配置项

## 四、核心使用流程与 AI 介入环节说明

### 核心使用流程

```
打开游戏
  ↓
首页（动态星河粒子背景 + 8 种猎物预览卡片）
  ↓
选择猎物类型（点击卡片选中，高亮 + ✓ 标记）
  ↓
点击「开始游戏」→ 自动进入全屏模式
  ↓
将设备平放，引导猫咪拍打屏幕上的猎物
  ↓
猫咪拍打猎物 → 得分 + 连击 + 粒子特效 + 音效反馈
  ↓
连击 5 次以上 → 触发「狂热模式」（速度提升 + 额外猎物）
  ↓
游戏 15 分钟后 → 智能休息提醒（降低亮度 + 舒缓提示）
  ↓
点击暂停按钮 → 下拉菜单（继续 / 调整设置 / 返回首页）
```

#### 自定义配置流程
1. 首页点击「自定义设置」进入编辑器
2. 调整猎物参数（大小 30-150px / 速度 1-10 / 颜色 / 运动模式）
3. 配置背景（颜色 / 渐变方向）与特效（类型 / 颜色 / 强度）
4. 设置游戏规则（猎物数量 1-15 / 休息间隔 1-60 分钟 / 音乐开关）
5. 保存并试玩，配置自动持久化到 `localStorage`

### AI 介入环节说明

CatChase 中的 AI 介入体现在**两个层面**：开发阶段的 AI 辅助开发，与应用内的 AI 交互设计。

#### 1. 开发阶段：AI 辅助开发（DuMate 平台）

整个项目基于百度 DuMate（秒哒）AI 开发平台，经 **20+ 轮对话迭代**完成：

| 阶段 | AI 介入环节 | 产出 |
|------|------------|------|
| 需求确认 | 自然语言描述游戏想法，AI 转化为技术方案 | 游戏设计方案 |
| 核心开发 | AI 生成 HTML 骨架与游戏逻辑代码 | Canvas 渲染引擎 + 点击检测 |
| 功能扩展 | 多轮对话逐步增加 8 种猎物与运动模式 | 完整猎物系统 |
| 音效系统 | AI 指导通过 Web Audio API 程序化合成音频 | 8 种专属音效 + 背景音乐 |
| 视觉升级 | AI 辅助设计星河粒子背景与毛玻璃 UI | 首页视觉系统 |
| 移动适配 | AI 提供全屏 API 与触摸优化方案 | 全平台响应式 |
| 调试优化 | AI 定位 bug 并提供修复建议 | 20+ 轮迭代打磨 |

**AI 辅助开发的核心价值**：
- **自然语言驱动**：用户描述需求，AI 转化为可运行代码
- **多轮对话迭代**：AI 记忆上下文，保持代码风格一致性
- **零素材开发**：AI 指导通过算法生成全部视觉与音频内容，实现单文件交付
- **开发周期缩短 80%+**：从想法到完整产品仅需 20+ 轮对话

#### 2. 应用内：AI 交互设计理念

CatChase 将 AI 交互设计理念融入游戏运行时，体现为四个智能功能：

**① 自适应难度算法**
```
输入：连击数、游戏时长、命中率
输出：猎物速度倍率、额外猎物数量
逻辑：连击↑ → 速度↑ + 额外猎物↑
      长时间无命中 → 速度↓（降低挫败感）
```

**② 智能休息提醒**
```
输入：游戏时长、活跃度
输出：休息提示触发
逻辑：时长 > 阈值 AND 活跃度高 → 触发休息
      缓慢降低屏幕亮度 + 舒缓音乐过渡
```

**③ 程序化音效合成**
非预录音频文件，通过 Web Audio API 实时合成 8 种猎物专属音效（正弦波/方波/噪声组合模拟不同动物声音特征）。

**④ 程序化背景音乐**
五声音阶（宫商角徵羽）算法生成随机旋律，每次游戏音乐不同，BPM 80-120 自适应调节。

## 五、技术栈清单

### 核心技术栈

| 类别 | 技术 | 用途 |
|------|------|------|
| 标记语言 | HTML5 | 页面结构与语义 |

| 持久化 | localStorage (Web Storage API) | 用户配置与游戏数据本地存储 |
| 交互 | Pointer Events API | 统一鼠标与触摸输入 |
| 全屏 | Fullscreen API | 游戏全屏模式与暂停退出 |

### 工程特性

- **纯前端单文件架构**：2876 行代码（HTML ~200 行 + CSS ~600 行 + JS ~2076 行），零外部依赖
- **响应式设计**：自适应手机 / 平板 / 电脑屏幕，支持设备像素比（DPR）适配
- **性能优化**：`requestAnimationFrame` 驱动渲染循环，多层渲染管线
- **零构建**：无需 webpack / vite / npm，打开即用
- **零素材**：无图片、无音频文件、无字体文件，全部内容程序化生成
- **类结构**：5 个核心类（Game / Prey / Particle / PreviewEngine / Audio），50+ 函数

### 浏览器兼容性

- Chrome 80+ / Edge 80+ / Safari 13+ / Firefox 75+
- 触屏设备（手机 / 平板）为推荐体验设备
