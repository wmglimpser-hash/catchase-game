# CatChase 猫咪互动游戏

专为家养猫咪设计的触屏互动游戏。

## 部署方式

本项目为纯静态 HTML 游戏，支持 GitHub Pages 直接部署。

### 部署步骤

1. 在 GitHub 创建新仓库（如 `catchase-game`）
2. 将本目录下所有文件推送到仓库
3. 进入 Settings > Pages
4. Source 选择 "Deploy from a branch"
5. Branch 选择 `main`，文件夹选择 `/ (root)`
6. 保存后约 1-2 分钟，访问 `https://你的用户名.github.io/catchase-game/`

## 访问地址

部署完成后，评审可通过以下链接访问：
`https://你的用户名.github.io/catchase-game/`

## 技术栈

- HTML5 / CSS3 / JavaScript
- Canvas 2D 渲染引擎
- Web Audio API 程序化音效
- localStorage 数据持久化
